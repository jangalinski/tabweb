# Package com.github.jangalinski.tabweb._foundation

Shared, non-widget infrastructure for the library. This package defines cross-concept semantic contracts such as `TabwebComponent`, `TabwebStyle`, `TabwebBehavior`, and `TabwebSize`, plus narrowly scoped shared value types.

Component APIs should use their owning concept package rather than expose `_foundation` implementation details.

See [Tabler base documentation](https://docs.tabler.io/ui/base).
